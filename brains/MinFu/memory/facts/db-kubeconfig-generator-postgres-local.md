Công cụ kubeconfig-generator dùng PostgreSQL với user và database cùng tên kubeconfig_generator. Host là postgresql.postgresql-local-fsel.svc.cluster.local, cổng 5432 (theo user, 2026-10-23). Mật khẩu do user tự đặt. Trạng thái đã tạo user và database trên Postgres chưa xác nhận (cần xác minh).
