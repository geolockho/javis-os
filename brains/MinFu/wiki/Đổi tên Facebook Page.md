## Các bước đổi tên

Trên máy tính, chuyển sang dùng Facebook với tư cách Trang, rồi mở Cài đặt và quyền riêng tư → Cài đặt → Thiết lập Trang → Tên để gửi yêu cầu đổi tên [[LouiseM - Change Facebook Page name]][[PinMeTo - How to change name on a Facebook page]][[Alejandro Rioja - How To Change Your Facebook Page Name]].

Trên điện thoại, mở Menu, chuyển sang Trang rồi vào Cài đặt và quyền riêng tư → Cài đặt → Cài đặt Trang → Tên [[LouiseM - Change Facebook Page name]][[PinMeTo - How to change name on a Facebook page]][[Alejandro Rioja - How To Change Your Facebook Page Name]].

Facebook có thể cần duyệt tên mới; thời gian duyệt và điều kiện quyền quản trị cần xác minh theo hướng dẫn hiện hành của Facebook [[LouiseM - Change Facebook Page name]][[PinMeTo - How to change name on a Facebook page]][[Alejandro Rioja - How To Change Your Facebook Page Name]].
