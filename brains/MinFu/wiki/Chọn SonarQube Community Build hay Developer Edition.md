`Application version` là phiên bản ứng dụng trong metadata của chart, còn Community Build và Developer Edition là các lựa chọn sản phẩm hoặc image; vì vậy hai thông tin này không cùng ý nghĩa. [[Chart SonarQube 2026.5.1004]]

Community Build phù hợp với quy trình theo dõi một nhánh chính; phân tích nhiều nhánh và phân tích Merge Request là khác biệt cần xem xét khi chọn Developer Edition. [[Bảng so sánh SonarQube Community Build]] [[Tích hợp GitLab SonarQube]]

Trước khi chọn edition, cần đối chiếu yêu cầu phân tích nhánh và Merge Request với bảng tính năng và tài liệu tích hợp của phiên bản SonarQube đang triển khai. [[Bảng so sánh SonarQube Community Build]] [[Tích hợp GitLab SonarQube]]
